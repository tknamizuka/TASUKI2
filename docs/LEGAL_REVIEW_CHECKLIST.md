# 法務レビューチェックリスト

本ドキュメントは、TASUKI アプリの利用規約・プライバシーポリシーに関する**外部法務レビュー（弁護士・顧問による確認）**の際に確認を推奨する項目をまとめたものです。特に HealthKit データおよび要配慮個人情報を含むため、専門家による確認を推奨します。

## 1. 確認を推奨する条項

| 区分 | 確認ポイント | 備考 |
|------|--------------|------|
| **HealthKit・要配慮個人情報** | 取得範囲、目的、同意の取得方法が適切か | 健康データは要配慮個人情報に該当する可能性が高い |
| **RealityMining オプトイン** | 登録規約との独立性、オプトアウトの容易さ | 規約同意とは別レイヤーであることが明記済み |
| **未成年** | 18歳未満利用禁止の記載・実装の整合 | アプリ側で18歳以上を前提にしている |
| **運営主体・連絡先** | 「当社」「TASUKIプロジェクト」が実際の法人・連絡先と一致しているか | 法務・実態に応じて修正が必要 |
| **管轄・準拠法** | 東京地方裁判所・日本法が適切か | 利用者・事業者の所在地に応じて検討 |
| **Firebase（海外サーバ）** | 個人情報の海外提供に関する説明の十分性 | プライバシーポリシーで言及済み |
| **退会・削除** | アカウント削除時のデータ削除方針 | 実装および規約での記載の整合 |

## 2. 改定・運用時の注意

- 規約・プライバシーポリシーを改定する際は、ユーザーへの事前告知を行う
- 新機能追加時（特に HealthKit、位置情報、新たなデータ収集）は、本チェックリストで再確認する
- 有料プランを実装する場合は、第5条・第6条を再改訂する
